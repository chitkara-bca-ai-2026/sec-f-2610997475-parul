Understanding Image Map Shapes

🔵 Circle

Defines a circular clickable area using the center coordinates and radius.

Example: United States, Australia and Japan.

🟦 Rectangle

Defines a rectangular clickable area using the top-left and bottom-right coordinates.

Example: Canada, China and the UK.

🔷 Polygon

Defines an irregular clickable region using multiple pairs of x and y coordinates.

Example: Brazil and India.

🌐 Default

Covers every part of the image that is not included in another defined area.

Example: Opens general world information.
